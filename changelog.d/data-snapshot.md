- **Recorded snapshot of data.** `mizzen data snapshot <name>` records a file collection's last commit and its date in `mizzen.lock.json`, and `mizzen data fetch` records the pinned version or hash and the data's own date for package and URL collections; the date always comes from the data, never the build clock. `:snapshot[field]` shows it in a template, `data/<name>.raw.json`, `.csv`, and `.sha256` ship the raw data with its checksum (`raw.private` leaves fields out, `raw: false` turns them off), `mizzen data verify` names the first record that differs from the lock without changing it, and `snapshot.maxAgeDays` makes `mizzen doctor` report a stale snapshot.
