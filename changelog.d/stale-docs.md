- **Stale page detection.** A page lists the files it describes in `covers` front matter; `mizzen stale mark` records their hashes in `docs-review.lock.json`, and `mizzen stale` (`--json`, `--fail`, `--changed`, `--git-diff <base>`) lists the pages whose files changed, were removed, or were added since. `mizzen check` and `mizzen doctor` report them as `stale.page` (severity from `stale.severity`, a warning by default), a moved file is told from a changed one by content hash, `recipes/stale-docs.yml` comments on pull requests with the pages a change touches, and the MCP tool `get_stale_pages` hands them to an agent. The build also attaches the state to `Page.stale` for the layout and writes it to the page's `index.json`, so a theme can mark a page that needs another read. Detection compares file contents only: no git history, clock, or network.
