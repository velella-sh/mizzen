# How to read a station

Every station is a record with its river and its install date. The
[riverside station](/stations/riverside/) is the reference, and the [station list](/stations/) is generated
from the same data file: a new station appears there without a page written by hand.

Read one station at a time. Its date is the install date, not the date of its last reading.

## What the numbers mean

A station records three things:

- the river it sits on,
- the date it was installed,
- a short description of where it stands.

The description is Markdown, so a station page can carry a list or emphasis. The guide is ordinary Markdown,
and the links above are ordinary links: a build reports one when a target record or list is missing.
