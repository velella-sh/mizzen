# Deploying beacon

## Before you start

::: tip Run the doctor first
`beacon doctor` checks credentials, the registry, and `beacon.yml` before anything is uploaded.
:::

::: warning
`beacon rollback` points an environment at an older artifact. It does not delete the newer one.
:::
