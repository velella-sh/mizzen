Publish a Mizzen site in three steps.

<Steps>

1. Build the site:

   ```sh
   node bin/mizzen.ts build site
   ```

2. Check the `site` output folder.
3. Upload the folder to a host.

</Steps>

The output looks like this:

<FileTree>

- site/
  - index.html
  - guides/
    - install/
      - index.html
  - sitemap.xml

</FileTree>

Read the [deployment guide](/guides/deploy/) before choosing a host.
