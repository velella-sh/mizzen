# import-starlight fixture

Two Starlight pages with the same content: `release.mdx` in MDX and `release.mdoc` in Markdoc. Each
has a Steps block, a FileTree, a LinkCard, and a custom component. They are import samples, not a
buildable site: the engine does not discover `.mdx` or `.mdoc` yet.

`docs/import-starlight-components.md` defines the expected converted content and the manual cases.
